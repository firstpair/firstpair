# Sail Declarative Pipelines

Spark Declarative Pipelines on Sail, the manual: pipeline projects in Python and SQL, materialized views and streaming tables, AutoCDC into Delta, Iceberg, Hive and Unity, Apache Iggy as a source, ORC, and the catalogs, for the unchanged Spark 4.2.1 client and spark-pipelines CLI.
