# Eigen Times History Math

A worked companion to Eigen Times Math History: twenty-one step-by-step lessons on least squares, probability, matrix methods, calibration, concept lattices, and neural representations, with a glossary, index, and complete executable Python and OCaml notebooks.

Current release: **1.1.0-99aa176a**. The reading editions and both notebooks
contain the complete expanded companion, with twenty-one worked lessons,
definitions before use, a glossary, and an index.
