# Personalized Learning from Working Systems

By Alexy Khrabrov. Published by First Pair Press — `firstpair.press`.

A scholarly methodology paper on learning from a working system through mathematical explanation, executable notebooks, definitions before use, targeted expansion, and a historical teaching arc.
