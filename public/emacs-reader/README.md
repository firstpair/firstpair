# The First Pair Emacs Reader Book

How First Pair Press built a reader for parallel texts inside GNU Emacs Info — two manuals and three windows, a dictionary that answers every word, any number of translations toggled and reordered in place, touch bars in a terminal, indirect Info files for big books, a self-verifying update path, and 1Unix, the iSH fork that turns an iPhone terminal into a full-screen hypertext reader — with the Emacs Lisp that does it.
